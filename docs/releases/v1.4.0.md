# Window Layouts v1.4.0

Window Layouts 1.4.0 adds automatic placement for newly launched applications.

## Highlights

- Map an application to any built-in or custom layout on a specific display.
- Choose whether placement should use the first eligible window or wait for a
  document window, supporting applications such as Microsoft Word and Excel
  that begin with a file or template chooser.
- Preserve macOS login restoration: automatic placement is disabled during the
  app's startup grace period and never runs when another instance of the mapped
  application is already open.
- Identify displays with public persistent display UUIDs and a conservative
  unique-name fallback.
- Keep stable and experimental update channels isolated while allowing each
  product to securely check, verify, install, and relaunch its own releases.

The update continues to use only public macOS APIs. App Sandbox remains
disabled because Window Layouts is an Accessibility client. No private APIs,
title-bar modification, privacy-control bypasses, telemetry, or third-party
dependencies are used.
