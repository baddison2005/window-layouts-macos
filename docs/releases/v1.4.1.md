# Window Layouts v1.4.1

Window Layouts 1.4.1 adds automatic application-window mappings and improves
reliability for applications with multi-stage launch flows.

## Highlights

- Map an application to a built-in or custom layout on a selected display.
- Choose whether to place the first eligible window or wait for a real document
  window, so launchers and document choosers can remain untouched.
- Reliably recognise Word and Excel document windows after opening or creating
  a file.
- Handle Keynote's Open window, theme chooser, conversion warnings, completed
  presentation editor, and launch-time window resizing.
- Retry transient windows that disappear while an application finishes
  launching, and correct later frame drift within a bounded settling period.

## Compatibility note

Automatic mapping uses only the public macOS Accessibility API. Applications
that expose unusual or incomplete Accessibility information may need an
app-specific workaround. Please report failures through GitHub Issues with the
application name and version, along with the sequence of launchers, choosers,
warnings, and document windows that appeared.
