# Window Layouts Experimental v1.4.2

This release fixes experimental Space movement for tested Adobe Acrobat windows.

## Changes

- Select a narrow title-bar margin below and clear of Acrobat's close button,
  avoiding its Home control and document tabs.
- Handle Acrobat's unimplemented Accessibility hit test using public macOS
  window geometry, requiring Acrobat to be frontmost and checking for overlapping
  windows at the gesture point.
- Exclude the Dock's full-display bookkeeping window from the obstruction check.
- Add diagnostic reasons for rejected points and regression tests covering the
  Acrobat margin, negative display coordinates, and existing input cleanup.

The feature still uses a left-mouse hold with Control–Left/Right Arrow and
remains opt-in. Native full-screen windows are unsupported, and unusual title
bars may require additional handling. Please report problems with your macOS
and application versions and the relevant diagnostic output.

## Installation

Download the universal ZIP or DMG below. Both support Apple silicon and Intel
Macs running macOS 14.6 or later and are Developer ID signed and notarized by
Apple. Move **Window Layouts Experimental.app** to Applications and grant its
requested Accessibility and input-event permissions. Quit other Window Layouts
copies while using this edition.

This is an official release on the experimental update channel. It retains its
separate application identity and settings. The stable edition remains v1.4.1.
