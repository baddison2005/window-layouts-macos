# Window Layouts v1.3.0

Window Layouts v1.3.0 adds portable JSON import and export for custom layouts
and groups.

## What's new

- Export custom layouts and named groups from **Settings → Layouts** to a
  readable JSON archive.
- Import an archive on another Mac or after reinstalling macOS.
- Preserve layout and group identifiers so custom layout relationships remain
  intact.
- Preserve unrelated preferences and valid keyboard shortcuts during import.
- Validate the archive before showing a replacement confirmation.
- Keep imported changes in the Settings draft until **Apply** is selected, so
  **Cancel** still discards them safely.

## Installation

- **DMG:** open `Window-Layouts-1.3.0-macOS.dmg` and drag **Window Layouts.app**
  to Applications.
- **ZIP:** extract `Window-Layouts-1.3.0-macOS.zip`, then move
  **Window Layouts.app** to Applications.

Both downloads contain the same universal application for Apple silicon and
Intel Macs. The app and DMG are signed with Developer ID and notarized by Apple.
macOS 14.6 or later is required.

Existing layouts, groups, preferences, and shortcuts remain in place when
upgrading from an earlier stable release.
