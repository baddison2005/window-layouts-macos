# Window Layouts Experimental v1.6.0

This release adds **Menu Bar Reveal**, an opt-in helper for the auto-hidden
macOS menu bar on MacBook and external displays.

- Pause near the top of a display to reveal its menu bar. Set the activation
  distance from 4 to 50 points.
- Keep the bar visible for up to 10 seconds after the pointer leaves the
  menu bar and activation zone. The default is 3 seconds. Returning to the
  bar cancels the countdown.
- Use the **Reveal Menu Bar** icon to show or release the bar. Disable the
  feature from Settings, the Window Layouts menu, or the app’s Dock menu.

To enable it, open **Settings → General → Experimental menu bar reveal**,
select **Help reveal the menu bar on any display**, and click **Apply**.

The helper uses a click-through popover and holds one menu bar at a time.
macOS decides which display hosts the icon that anchors it. On stacked
displays, a hover can miss, and interacting with a native menu or changing
the active display can end the hold early. When macOS reveals the bar on
its own, the system controls when it hides.

The ZIP and DMG contain the same Developer ID-signed, notarized universal
app for Apple silicon and Intel Macs running macOS 14.6 or later. This
release is on the experimental update channel.
