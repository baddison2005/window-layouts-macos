# Window Layouts Experimental v1.3.0

This prerelease adds an opt-in experiment for moving the active window between
macOS Spaces and portable JSON import/export for custom layouts and groups. It
uses a separate application identity and settings library, so it can be tested
without replacing the stable Window Layouts app.

## Highlights

- Move eligible windows to the previous or next Space using configurable global
  shortcuts, the menu bar, Dock menu, or green-button panel.
- Export custom layouts and groups to JSON, then import them on another Mac or
  after reinstalling macOS.
- Keep the experimental app, permissions, settings, and update behavior isolated
  from the stable release.

## Installation

- **DMG:** open `Window-Layouts-Experimental-1.3.0-macOS.dmg` and drag
  **Window Layouts Experimental.app** to Applications.
- **ZIP:** extract `Window-Layouts-Experimental-1.3.0-macOS.zip`, then move
  **Window Layouts Experimental.app** to Applications.

Both downloads contain the same universal app for Apple silicon and Intel Macs.
The app and DMG are signed with Developer ID and notarized by Apple. macOS 14.6
or later is required.

Quit the stable Window Layouts app while testing. On first launch, grant the
experimental app Accessibility and Input Monitoring access. Space movement also
requires **Move left a space** and **Move right a space** to be enabled as
Control–Left Arrow and Control–Right Arrow in macOS Mission Control keyboard
shortcut settings.

## Experimental Space movement warning

macOS has no public API for assigning another application's window to a Space.
This feature reproduces the normal mouse-hold and Mission Control keyboard
gesture using public Quartz event APIs. It is inherently app-dependent and
cannot verify the destination Space.

Some apps expose incomplete or misleading title-bar Accessibility information.
Movement may fail, activate an unexpected title-bar control, or behave
unexpectedly. Adobe Acrobat is a known incompatible case in this build. Native
full-screen windows are not supported, and future macOS updates may affect the
feature.

This is a GitHub prerelease for testing, not a stable update. Please report the
application, macOS version, window state, and observed behavior with any issue.
